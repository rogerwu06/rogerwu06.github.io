Wind Load Generation in STAAD Following Canadian NBCC 2020 Codes

Generates STAAD member wind loads from node geometry, member connectivity, section properties, and wind parameters in the X and Z directions.

Initial Design Note

This tool is intended for initial design. It uses conservative worst-case member loading in both the X and Z directions and checks both section depth and width when determining load. Components that are not represented in the STAAD model, such as piping or cable trays, require separate consideration.
