Automated Creation of Abaqus Pipe Models from 3D Geometries up to Meshing

Automates recreation of a pipe-connection Abaqus model around replacement 3D geometry. The program imports a STEP/STP model into an existing CAE model and transfers model definitions including contacts, materials, boundary conditions, and operating-pressure loading through the modelling steps up to meshing.

Limitations

The current automation is intended for the expected run, branch, and reinforcement geometry. It may not map the model correctly when additional bodies are present or when the replacement geometry has substantially different topology. Face and set mapping should be checked in Abaqus after transfer.

Download

Download Python file (.py)

Steps

  • Select an existing Abaqus CAE, replacement STEP/STP geometry, and Abaqus launcher.
  • Create a timestamped backup before updating the selected CAE.
  • Match replacement parts using normalized geometry and assembly arrangement.
  • Transfer the existing model setup to the replacement geometry through meshing.
  • Create a live log and transfer report for checking.

Tools: Abaqus/CAE, Python, STEP geometry
